# Execution Fidelity Guard

- Preserve the frozen product input and distinguish platform facts, product judgments, and unvalidated hypotheses.
- Keep this repository an installable plugin, not a replacement Agent harness.
- Deterministic hard blocks require positive, negative, and failure-regression tests.
- Semantic review may remind, nominate a user question, or request verification, but cannot hard-block alone.
- Plugin failures must never weaken Codex sandboxing, approvals, or other native controls.
- Do not install, enable, publish, or add this plugin to a marketplace without explicit user authorization.
