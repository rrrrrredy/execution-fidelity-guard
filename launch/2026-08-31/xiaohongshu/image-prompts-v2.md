# Xiaohongshu image set v2

Generation mode: built-in `imagegen`. Each asset was generated separately; the cover and evidence table received one accuracy edit before acceptance.

## Shared direction

Human editorial print design: warm off-white uncoated paper, black typography, restrained vermilion proofreader-pencil accents, real paper grain, strict Swiss grid, and generous negative space. Explicit exclusions: shield/robot/brain/circuit imagery, network diagrams, floating app cards, glassmorphism, 3D/isometric objects, glossy gradients, neon glow, and blue-purple palettes.
